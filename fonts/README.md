# Fonts

These fonts are drawn into clips and edits (captions, hooks, cards). Copies of the same files live in
`static/fonts/` so the page can show them too.

| File | Used for | Licence |
|---|---|---|
| `Anton-Regular.ttf` | big hook and headline words, edit text | SIL Open Font License 1.1 (`OFL-Anton.txt`) |
| `Poppins-Bold.ttf` | captions, labels | SIL Open Font License 1.1 |
| `Poppins-Regular.ttf` | small text, subtitles | SIL Open Font License 1.1 |

Both families are free to use in videos, including paid campaigns. Keep the file names as they are: the code looks
for them by name.
